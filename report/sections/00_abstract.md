# Abstract

Newborns in India must receive vaccines in a fixed sequence at set ages, from birth to the boosters at 16–23 months, while clinics must also keep track of vaccine batches and their expiry dates. Paper cards and spreadsheets make it easy to miss a dose, to give a vaccine from an empty or expired batch, or to lose track of who changed a record. VaxTrack is a newborn vaccination schedule tracker built on Oracle Database 21c Express Edition, in which PL/SQL owns every business rule. The vaccination schedule of the National Immunization Schedule is stored as data and expanded into 24 dose records per baby (26 in districts where Japanese encephalitis is endemic). Four packages, five standalone functions, one standalone procedure, five triggers, explicit, parameterized, FOR-loop and REF cursors, and a DBMS_SCHEDULER job handle scheduling, dose administration with first-expiry-first-out stock deduction, overdue detection, alerts and auditing. A Node.js and Express API passes requests to the packages, and a React web application serves three kinds of users: administrators, nurses and parents. The behaviour was verified with 31 automated PL/SQL test cases, 152 API checks and browser tests. The project covers infants and the 16–23 month boosters.

**Keywords:** DBMS, Oracle PL/SQL, Packages, Triggers, Cursors, Normalization, Immunization Schedule
